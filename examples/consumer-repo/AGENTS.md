# Quality standards

This repo follows the shared standards in https://github.com/noshpotosh/qa.
Before writing or reviewing UI, styles or structural changes, read the matching
skill from that repo (`skills/<name>/SKILL.md`). If it is checked out locally,
it lives at `.qa/skills/`.

## Repo-specific overrides
- Token file: `src/styles/tokens.css`
- Layers: `ui -> features -> domain -> lib`
